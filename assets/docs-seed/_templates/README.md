# Templates

This folder contains reusable note templates.

Use templates when a document has a repeated structure, such as decision records or module notes.

Templates should stay small. They guide document shape without replacing thinking.

The task memory templates (`task-goal.md`, `task-diagram.md`, `task-memories.md`) are samples. A project may add, reorder, or rename their sections, but must keep the Compass-required headings listed under `required-headings` in the Compass skill's `references/task-memory.xml`.
